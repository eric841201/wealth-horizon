## 🚀 核心特色與演算法設計

### 1. 雙水庫動態溢流機制 (Dynamic Watermark Engine)
* **防禦水庫 (高利活存)**：
  * 目標封頂：**NT$ 120,000**（每月提撥上限 $15,000）。
  * 達到 12 萬瞬間自動觸發「金色防禦盾牌完全充能」，保護日常生活安全網。
* **進攻水庫 (0050 ETF)**：
  * 活存未滿時：每月注入 $15,000。
  * **活存滿額後：系統自動感應，未來每月 $30,000（或更多）100% 全額溢流至 0050**。
* **動態感應與回補**：
  * 若領到年終/獎金結餘，可一鍵勾選「加速補滿」，缺口補齊後其餘直接溢流到 0050。
  * 若未來有緊急支出提領活存，系統自動感應缺口並在下次存入時自動重啟分流補血。

### 2. 調薪與收入變動 (歷史與未來解耦)
* **調薪不必重設過去**：
  * 過去存的每一筆流水帳真實保留。
  * 點擊右上角「**策略參數**」，將「每月預設存入本金」從 30,000 調整為 33,000（或任何金額）。
  * 系統會以「**當前已累積總資產**」為新起點，即時重新推算未來的複利曲線，100 萬與 1000 萬的「預計達標年月」與倒數天數會**立即往前縮短跳動**。

### 3. 實務情境支援
* **0050 真實市值校準**：券商股票上漲時，點擊「市值/配息校準」，填入最新現值，立即校正淨值與享受進度暴衝快感。
* **0050 股息再投入**：每年 1 月、7 月領到股息，可一鍵記錄並滾入複利。
* **RPG 里程碑大地圖**：2/5 啟航 ➔ 12萬安全防線 ➔ 25萬初露鋒芒 ➔ 50萬半桶金 ➔ 100萬第一桶金 ➔ 300萬 ➔ 500萬 ➔ 1000萬自由，成就感拉滿。
* **資料本機私密保護 (LocalStorage)**：資料儲存於您的瀏覽器本地，並支援匯出 JSON 備份檔。

## 💻 快速開啟方式

1. **直接開啟**：用任何瀏覽器（Chrome、Edge、Safari、手機瀏覽器）直接開啟 `index.html`。
2. **本機伺服器（推薦）**：
   * 在終端機執行：
     ```bash
     python -m http.server 8085
     ```
   * 瀏覽器開啟：`http://localhost:8085`
   * 手機只要與電腦在同一個 WiFi 下，打開 `http://<電腦IP>:8085` 即可使用。
